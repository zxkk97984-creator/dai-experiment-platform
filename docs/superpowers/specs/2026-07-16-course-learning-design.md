# 课程学习流前端设计 — 课程详情页 + 课时阅读页

## 元信息

- **日期**：2026-07-16
- **范围**：学生端课程详情页（CourseDetailView）和课时阅读页（LessonView）
- **设计方向**：Pythonista — 技术文档风，深蓝+暖黄点缀，暗色代码块
- **设计系统**：沿用现有 tokens（Prussian blue `#1A5C8A`, cadmium orange `#E0553D`, DM Serif Display + IBM Plex Sans + IBM Plex Mono）

---

## 一、课程详情页 — 课程门户

### 页面职责

学生选课后进入的课程主页，一站式查看课程信息、学习进度、作业/考试快捷入口和章节目录。

### 布局结构

```
┌──────────────────────────────────────────────┐
│  ← 返回课程列表                               │
│                                               │
│  ┌─ 课程信息卡片 ────────────────────────────┐│
│  │  课程名称（DM Serif Display）              ││
│  │  简介文字（muted slate）                   ││
│  │  教师 + 人数 + 章数 stats                  ││
│  │  学习进度条（镉橙 accent）                 ││
│  └────────────────────────────────────────────┘│
│                                               │
│  ┌─ 作业快捷入口 ────────────────────────────┐│
│  │  作业列表卡片，每条显示标题 + 提交状态      ││
│  └────────────────────────────────────────────┘│
│                                               │
│  ┌─ 考试快捷入口 ────────────────────────────┐│
│  │  考试列表卡片，显示时长 + 状态              ││
│  └────────────────────────────────────────────┘│
│                                               │
│  ┌─ 章节目录 ────────────────────────────────┐│
│  │  第 N 章  章节标题                         ││
│  │  ├── 📖 课时名                    ✓ 已完成 ││
│  │  ├── 🎥 课时名                             ││
│  │  └── 📓 课时名              🔒 未开放      ││
│  └────────────────────────────────────────────┘│
└──────────────────────────────────────────────┘
```

### 数据流

```
GET /courses/{id}          → course 信息
GET /courses/{id}/chapters → chapters[] + lessons[]
GET /assignments?course_id={id}  → 作业列表（快捷入口）
GET /exams?course_id={id}        → 考试列表（快捷入口）
GET /courses/{id}/enroll   → 选课状态（未选课时显示选课按钮）
```

### 交互行为

| 交互 | 行为 |
|------|------|
| 点击课时 | 跳转 `/student/courses/{cid}/lessons/{lid}` |
| 点击作业卡片 | 跳转作业详情 |
| 点击考试卡片 | 跳转考试页面 |
| 点击返回 | 回到课程列表 |
| 未选课状态 | 章节区域替换为"请先选课"+ 选课按钮 |
| 选课按钮 | `POST /courses/{id}/enroll` → 刷新页面 |

### 状态覆盖

| 状态 | 展示 |
|------|------|
| 加载中 | 骨架屏：卡片骨架 + 章节行骨架（3-5行） |
| 加载失败 | toast 提示 "加载课程失败" + 空状态 |
| 课程不存在 | 空状态卡片 + "返回课程列表" 链接 |
| 无章节 | "暂无章节内容" 空状态 + 页面介绍 |
| 无课时 | 章节展开后显示 "暂无课时" |
| 无作业/考试 | 对应区块不渲染，或显示 "暂无" |
| 未选课 | 章节区域显示选课引导，出现 "选课" 按钮 |

### 空状态设计

- 文案使用引导性语言，不道歉
- 无章节时：显示课程名称和简介信息卡仍然可见，章节区域显示 "教师正在准备课程内容..."
- 未选课时：信息卡仍可见，章节区域引导选课

## 二、课时阅读页 — 技术文档风格

### 页面职责

渲染教师上传的课时内容（Markdown / 视频 / Notebook），提供章节内导航和跨课时跳转。

### 布局结构

```
┌──────────────────────────────────────────────┐
│  📖 课程名 › 第X章 › 课时标题                  │
│  [📂 快速跳转 ▾]  ← 章节下拉选单               │
│                                               │
│  ═══════════════════════════════════════════  │
│                                               │
│  (Markdown 渲染内容)                           │
│  - 标题层级 H1/H2/H3                          │
│  - 表格                                       │
│  - 代码块（暗色底 + 行号 + IBM Plex Mono）     │
│  - 引用/提示块（暖黄底色 + 左边框）             │
│  - 图片                                       │
│                                               │
│  ═══════════════════════════════════════════  │
│                                               │
│  ← 上一课：xxx          下一课：xxx →          │
└──────────────────────────────────────────────┘
```

### 数据流

```
GET /courses/{id}/chapters → chapters[] + lessons[]（构建导航数据）
从 chapters 中找到当前 lesson（lid 匹配）
lesson.content_type 决定渲染模式
```

### 课时类型渲染

| content_type | 渲染方式 |
|-------------|---------|
| `markdown` | v-html 渲染 Markdown 内容。后端返回已转换的 HTML，前端直接渲染。标题/表格/代码块/引用通过 scoped CSS `:deep()` 选择器定制样式 |
| `video` | 显示视频嵌入区或外链按钮。使用 `lesson.video_url`。若 URL 为空，显示 "视频暂不可用" |
| `notebook` 或默认 | 显示课时描述 + "在 JupyterLab 中打开" 按钮。使用 `lesson.notebook_path`，调用 `/jupyter/entry` 获取 iframe URL 后打开 |

### 交互行为

| 交互 | 行为 |
|------|------|
| 面包屑点击 "课程名" | 返回课程详情页 |
| 章节下拉选单 | 快速跳转到任意课时（同课程内） |
| 上一课/下一课 | 跳转到相邻课时 |
| 上一课（第一章第一节）| 按钮 disabled |
| 下一课（最后一章最后一节）| 按钮 disabled |
| JupyterLab 按钮 | 调用 `/jupyter/entry` → 新标签页打开或 iframe |

### Markdown 内容样式规范

- **H1**：`font-family: var(--font-display)`, `font-size: var(--text-2xl)`, `font-weight: 400`
- **H2**：`font-family: var(--font-display)`, `font-size: var(--text-xl)`, 顶部有分隔线
- **H3**：`font-size: var(--text-md)`, `font-weight: 600`, 无装饰
- **段落**：`line-height: 1.8`, `margin: 12px 0`
- **代码块（pre > code）**：暗色底 `#1A1E2B`，`IBM Plex Mono`，带行号侧栏，`border: 1px solid #2A3040`。这是 Pythonista 风格的签名元素
- **行内代码（code:not(pre code)）**：浅灰底 `var(--surface-raised)`，红色字 `var(--danger)`，小字号
- **表格**：标准边框表格，表头 uppercase + 小字号
- **图片**：`max-width: 100%`, `border-radius: var(--radius-md)`
- **引用块（blockquote）**：暖黄底色 `var(--warning-light)` + 左边框 `var(--warning)`，内边距宽松
- **提示块**（通过 CSS class 区分）：💡提示 / ⚠️注意 / 🔥重点 三种

### 导航设计

- **面包屑**：顶部，muted slate 字体，`课程名 › 第X章 › 课时标题`。课程名可点击返回
- **章节下拉**：面包屑右侧，`[📂 快速跳转 ▾]` 按钮，点击弹出下拉选单，按章节分组列出所有课时，当前课时高亮
- **底部导航**：固定在内容底部，左右两个按钮 `← 上一课：xxx` 和 `下一课：xxx →`，hover 显示完整课时名。边界课时对应按钮 disabled

### 状态覆盖

| 状态 | 展示 |
|------|------|
| 加载中 | 内容区骨架屏：标题占位 + 段落占位行 x8 |
| 加载失败 | toast + 空状态卡片 |
| 课时不存在 | "课时不存在" 卡片 + "返回课程" 按钮 |
| 空内容 | "该课时暂无内容，教师正在准备中..." |
| Markdown 内容为空 | 同上空内容状态 |
| 视频 URL 为空 | "视频暂不可用" 提示 |
| 无上一课 | 左按钮 disabled |
| 无下一课 | 右按钮 disabled |
| 章节为空 | 跳转选单显示 "暂无其他课时" |

## 三、与现有设计系统的一致性

- 使用项目已有的 CSS tokens（`--ink`, `--paper`, `--surface`, `--primary`, `--accent`, `--border` 等）
- 代码块暗色板 `#1A1E2B` 与 AssignmentDetailView 编辑器一致
- 字体系统保持一致：`DM Serif Display`（标题），`IBM Plex Sans`（UI），`IBM Plex Mono`（代码）
- 右箭头、返回图标等沿用现有 SVG icon 风格

## 四、Pythonista 签名元素

1. **暗色代码块**：所有代码块使用 `#1A1E2B` 深色底 + 行号，和平台代码编辑器形成视觉呼应，这是"Python 教学平台"的核心视觉识别
2. **暖色引用块**：blockquote / 提示块使用 `--warning-light` 暖黄底色，模拟 Python REPL 的暖色输出感
3. **进度条**：课程详情页的学习进度条使用 `--accent` 镉橙，像 Python logo 的黄色
4. **图标语义**：📖 讲义 / 🎥 视频 / 📓 Notebook 三种课时类型使用统一的 emoji 图标系统，简洁不做作
