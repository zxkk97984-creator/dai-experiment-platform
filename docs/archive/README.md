# 文档归档说明

本目录保存已经完成的调查、收口报告和历史计划，仅用于追溯当时的背景、验证记录和决策上下文。

归档文档不是当前系统的运行说明，也不是部署依据。需要了解当前实现时，以以下内容为准：

- [`README.md`](../../README.md)：项目定位、启动、部署和验证入口；
- [`架构设计总览.md`](../架构设计总览.md)：当前系统架构与模块边界；
- [`environment-profiles.md`](../environment-profiles.md)：环境档位与构建运维手册；
- `docs/security/`：当前安全门禁和部署安全要求。

归档内容保留原始日期和结论，不随当前代码自动更新。
