# 认识 Python

## Python 是什么？
Python 是一种**解释型、面向对象**的高级编程语言，由 Guido van Rossum 于 1991 年首次发布。

### 为什么学 Python？
- 📖 **语法简洁**：接近自然语言，上手快
- 🔧 **用途广泛**：Web开发、数据分析、人工智能、自动化脚本
- 🌍 **生态丰富**：海量第三方库（NumPy、Pandas、PyTorch...）
- 👥 **社区活跃**：遇到问题容易找到答案

### Python 的特点

| 特点 | 说明 |
|------|------|
| 解释型 | 代码逐行执行，无需编译 |
| 动态类型 | 变量不需要声明类型 |
| 强缩进 | 用缩进组织代码块 |
| 跨平台 | Windows / macOS / Linux 都能运行 |

### 第一个 Python 程序

```python
print("Hello, World!")
```

在浏览器中直接运行这段代码，试试看！
