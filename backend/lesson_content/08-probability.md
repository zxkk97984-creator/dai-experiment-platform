# 概率论基础

## 概率基本概念
概率描述事件发生的可能性，取值 0（不可能）到 1（必然）。

### 基本公式
- **概率**：P(A) = 事件A发生数 / 总情况数
- **补事件**：P(¬A) = 1 - P(A)
- **和事件**：P(A∪B) = P(A) + P(B) - P(A∩B)

## 条件概率
P(A|B) 表示在 B 发生条件下 A 发生的概率：

```
P(A|B) = P(A∩B) / P(B)
```

### 贝叶斯定理
机器学习中最重要的公式之一：

```
P(A|B) = P(B|A) × P(A) / P(B)
```

> 贝叶斯定理告诉我们：在新证据出现时，如何更新我们对某个假设的信念。

## 常见概率分布

```python
import numpy as np

# 正态分布
normal = np.random.normal(loc=0, scale=1, size=1000)

# 均匀分布
uniform = np.random.uniform(low=0, high=1, size=1000)

# 二项分布（n次试验，每次成功概率p）
binomial = np.random.binomial(n=10, p=0.5, size=1000)
```

| 分布 | 用途 | 参数 |
|------|------|------|
| 正态分布 | 身高、误差 | μ(均值), σ(标准差) |
| 二项分布 | 抛硬币成功次数 | n, p |
| 均匀分布 | 等可能性事件 | a, b |
| 指数分布 | 等待时间 | λ(速率) |
| 泊松分布 | 稀有事件计数 | λ(均值) |

## 期望与方差
```python
data = np.array([1, 2, 3, 4, 5])
print(np.mean(data))  # 3.0 — 均值（期望）
print(np.var(data))   # 2.0 — 方差
print(np.std(data))   # 1.414 — 标准差
```

## 大数定律与中心极限定理
- **大数定律**：样本越多，样本均值越接近总体均值
- **中心极限定理**：大量独立随机变量的均值近似服从正态分布

## 在机器学习中的应用
- 朴素贝叶斯分类器（垃圾邮件过滤）
- 最大似然估计（MLE）
- 贝叶斯优化（超参数调优）
- 生成模型（VAE、GAN、Diffusion）
