Design System Redesign · V2

DAI Design System V2

「墨松绿 × 岩灰」——一套面向数据科学、编程实验与 AI 教学的专业教育实验平台视觉体系。与上一版 Kaggle Inspired 基线在色彩、字体、密度、控件与组件上全面重构，而非换皮。

Direction rationale

从三个配色方向中选定「墨松绿 × 岩灰」

墨松绿 × 岩灰

选定

绿色直接对应「判题通过 / 正确 / 已验证」的产品语义；暖岩灰背景避免冷白，适合长时间工作；与 V1 的蓝 / 橙彻底区分，耐看且克制。

朱砂 × 纸墨

未采用

学术纸墨气质强，但红 / 橙在评分语境易与「错误」混淆，长期使用存在语义风险。

石墨 × 靛蓝

未采用

工程感强，但仍属蓝紫系，与 V1 蓝色区分度不足，且用户明确要求避开蓝紫。

Key decisions

与上一版的核心差异

色彩

绿语义替代蓝主题

品牌色从 Cyan / 蓝切换为墨松绿；数据可视化使用独立分类色板，AI 不再用紫色。

字体

衬线标题 + 黑体正文

标题用思源宋体建立学术工作台性格，正文用思源黑体，数字与代码等宽；替换 Inter + 单一黑体。

密度

更高信息密度

侧栏 232px、表头 56px、行高 40–44px、页边距 24px；表格成为一等公民，减少「卡片化一切」。

控件

矩形控件替代 Pill

圆角收紧至 3 / 5 / 7px，筛选用矩形 Filter Chip，按钮主色只出现一次，聚焦为绿描边。

导航

浅色分组侧栏

从深色侧栏改为浅岩灰侧栏，按教学 / 评分 / 系统分组，激活态为绿左栏，可收起为 56px 图标栏。

AI

证据来源而非魔法

确定性测试用实线、AI 判断用虚线、教师决策用绿实线；一眼区分「事实 / 建议 / 终审」。
