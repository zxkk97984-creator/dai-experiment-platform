03 · Button System

按钮

每屏只保留一个品牌色主按钮；其余用次要 / 幽灵 / 危险。高度 32–36px，圆角 5px，主按钮悬停加深绿色而非变灰。

聚焦状态统一为 2px 墨松绿描边 + 2px 偏移；悬停态均加深或移位，不用「变灰文字」。

04 · Input System

输入框

32px 高度、5px 圆角、发丝线边框；聚焦为墨松绿描边 + 浅绿光环。校验态通过边框与辅助文字表达。

用于课程列表展示
请输入有效名称

05 · Select System

下拉选择

矩形边框控件，非 Pill；紧凑用于工具栏，标准用于表单。多选下拉用「复选 + 计数」表达。

06 · Search System

搜索

矩形搜索框，含图标、清空按钮与键盘快捷键提示；列表页复用同一组件。

⌘K

07 · Tabs System

Tabs

文字 + 短墨松绿下划线；选中态用文字加粗 + 2px 强调线，非整排胶囊。计数用等宽小标签。

Tab 之间可横向滚动，不换行；移动端保持可读。

08 · Filter System

筛选

筛选使用矩形 Filter Chip 或分段控件，激活态为墨松绿描边 + 浅绿底；避免整排 Pill。

分段控件用于视图切换与短期状态，不与筛选 Chip 混用。

09 · Badge / Status System

状态徽标

浅底 + 圆点 + 语义色文字，3px 小圆角；密集表格中可用无底色的「圆点 + 文字」降噪。

10 · Card / Surface System

卡片与表面

减少「每块内容一个圆角矩形」：结构化数据用表格，分组用区块标题 + 发丝线 + 浅底，仅关键面板使用 7px 圆角卡片。

Panel

标准面板

带标题栏的面板，用于需要独立语义边界的内容块，如评分依据、课程信息。

Flat region

扁平区域

无边框、靠留白与标题分隔的内容，用于统计条与长表单分组。

Subtle surface

浅色表面用于代码块、表头、斑马纹与次级工作区。

11 · Table System

表格

一等公民：贴齐发丝线、粘性表头、42px 行高、悬停 / 选中 / 批量态、数字右对齐、长文本省略。适用于课程 / 学生 / 提交 / 成绩 / 实验。
